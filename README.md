### Engineering principles

- **Evaluation precedes modeling.** Metrics harnesses and leakage checks are built and unit-tested before any model exists, so every approach downstream is scored under identical conditions.
- **Guardrails fail closed by default.** Safety and topic classifiers block the request on any classifier error rather than defaulting to open; the rare intentional exception is documented in the repo, not incidental.
- **Promotion and rollback decisions are statistically gated**, not point-estimate driven, using paired significance tests with bootstrap fallbacks for small-sample regimes.
- **Design tradeoffs and known failure modes are documented directly in each project** rather than left implicit, including prior bugs (feature leakage, race conditions, false-positive rollback triggers) and how they were resolved.
